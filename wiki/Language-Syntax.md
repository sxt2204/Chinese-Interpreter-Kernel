# 中文语法与特性指南 (Language Syntax Guide)

本文档详细说明 **Chinese-Interpreter-Kernel** 支持的中文编程语言语法、数据类型、运算符及高级表达方式。

---

## 1. 数据类型

解释器内置支持以下基础数据类型：

| 中文类型关键字 | 映射数据类型 | 示例 |
| :--- | :--- | :--- |
| **`整数`** | `int` | `整数 计数 等于 10` |
| **`双精度小数`** | `double` | `双精度小数 圆周率 等于 3.14159` |
| **`文本`** | `std::string` | `文本 消息 等于 "Hello World"` |

---

## 2. 变量声明与赋值

- **赋值关键字**：使用 **`等于`** 替代传统英文的 `=` 符号。

### 示例
```chinese
整数 数量 等于 100
文本 标题 等于 "中文解释器"
双精度小数 价格 等于 99.9
```

---

## 3. 运算符与比较表达

### 3.1 算术运算符

| 中文运算符 | 替代符号 | 说明 |
| :--- | :--- | :--- |
| **`加`** | `+` | 适用于数值相加或字符串拼接 |
| **`减`** | `-` | 数值相减（或单目负号 `-`） |
| **`乘`** | `*` | 数值相乘 |
| **`除`** | `/` | 数值相除 |
| **`取模`** | `%` | 数值取余数 |

### 3.2 比较运算符

| 中文比较词 | 替代符号 | 说明 |
| :--- | :--- | :--- |
| **`等于`** | `==` (比较) / `=` (赋值) | 在条件表达式中自动识别为 `==` |
| **`不等于`** | `!=` | 比较是否不相等 |
| **`大于`** | `>` | 大于比较 |
| **`小于`** | `<` | 小于比较 |
| **`大于等于`** | `>=` | 大于或等于 |
| **`小于等于`** | `<=` | 小于或等于 |

---

## 4. 流程控制与 Python 式自然缩进

解释器语法分析器采用 **缩进感知机制（Indent / Dedent）**，代码块的作用域完全通过**制表符/空格缩进**管理。**无需手写 `结束如果`、`结束当` 或 `结束函数`！**

### 4.1 条件判断 (`如果 ... 那么`)

```chinese
如果 分数 大于等于 60 那么
    输出并换行（"考试及格"）
    输出并换行（"继续保持"）
```

### 4.2 循环控制 (`当 ... 循环`)

```chinese
整数 计数 等于 1
当 计数 小于等于 5 循环
    输出并换行（"当前计数：" 加 计数）
    计数 等于 计数 加 1
```

---

## 5. 函数定义与递归

使用 **`定义函数`** 关键字声明函数，使用 **`返回`** 导出返回值：

### 5.1 普通函数
```chinese
定义函数 相加（数值一，数值二）
    返回 数值一 加 数值二

整数 结果 等于 相加（10，20）
输出并换行（结果）
```

### 5.2 递归函数（计算阶乘）
```chinese
定义函数 阶乘（数值）
    如果 数值 小于 2 那么
        返回 1
    返回 数值 乘 阶乘（数值 减 1）

整数 结果 等于 阶乘（5）
输出并换行（"5的阶乘为：" 加 结果）
```

---

## 6. 面向对象与方法链调用

解释器支持 `对象.方法（参数）` 形式的成员函数调用以及 `对象.属性` 形式的成员变量访问。

### 示例（调用 C++ `StringObject` 扩展类）

```chinese
文本 消息 等于 "Hello World"

; 调用对象的方法
整数 长度 等于 消息.获取长度（）
输出并换行（"消息长度为：" 加 长度）
```
输出：
```
消息长度为：11
```
